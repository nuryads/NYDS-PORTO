## 👋 About Me

Halo! Saya **Muhammad Nuryadi**, seorang Graphic Designer berbasis di Jakarta, Indonesia, dengan pengalaman lebih dari 6 tahun di bidang desain grafis, desain tekstil, apparel, dan produksi kreatif.

Saya memiliki spesialisasi dalam **Vector Tracing, Textile Pattern Design, Jersey Design, dan Social Media Content**.

Dengan pengalaman dalam proses produksi digital printing, saya terbiasa mengembangkan desain mulai dari pengolahan visual hingga persiapan artwork untuk kebutuhan produksi.

Saya juga terus mengeksplorasi teknologi AI sebagai bagian dari pengembangan ide dan kreativitas desain.
